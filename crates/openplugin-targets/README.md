# openplugin-targets

Format entries for OpenPluginSDK plugins: `export_clap!` and `export_lv2!` in Rust, and `export_shell!`, the C ABI the native VST3, Audio Unit and AAX shells link.

Part of [OpenPluginSDK](https://github.com/MistaMin/OpenPluginSDK), a Rust audio plugin SDK without JUCE. See the repository README for an overview and examples.
